Rules
✓ Do
  • Anchor every page on cream canvas #fffaf0
  • Cycle 6 brand-color cards: pink → teal → lavender → peach → ochre → cream
  • Display headlines: weight 500 with negative letter-spacing
  • Use cream footer — Clay never uses a dark footer
  • Show product UI fragments inside colored cards
  • 96px between major editorial bands
✗ Don't
  • Use cool grays for canvas — the cream tint is non-negotiable
  • Repeat the same brand-color card twice in a row
  • Bold display weight beyond 500 — reads as bombastic
  • Add a 7th brand-color card variant
  • Replace claymation illustrations with flat vector art
  • Use a dark footer
