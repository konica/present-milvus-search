What We Built

  • Automated reviews — Replaces manual triage for common issues in pull requests
  • Under 60 seconds — Reviews run fast; inline comments posted directly on the PR
  • Three components — Data fetch, reasoning, and code intelligence cleanly separated
  • Token-efficient — PR data injected once via Python; zero read MCP calls during review

Key Design Decisions

  • PR data pre-fetched in Python — No MCP read round-trips; saves tokens and latency
  • Serena for code intelligence — On-demand symbol lookup, only when a breakage is suspected
  • Bitbucket MCP write-only — Scoped to add_pull_request_comment; easy to audit

Result: 3–5 fewer MCP round-trips per review, ~15–20% token reduction.
